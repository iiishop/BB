## BB 0.1.2

这次修两处空间的小毛病。空间功能本身与 0.1.1 相同。

### 修复

- **换过头像，空间里还是旧图**。问题在客户端：空间页给每个作者的头像只在本页缓存一次，而「刷新」只重拉帖子，不动头像。现在下拉刷新会连头像一起重新校验 —— 没变的走 304，几乎零成本。
- **帖子少的时候下拉刷新没反应**。列表内容不满一屏时无法滚动，下拉手势被吞掉。现在不管内容多少都能下拉。

### BB 空间

说说流、草稿、任意深度回复、转发链、删除语义、已读与浏览分离、通知路由，手机 / PC / 折叠屏三形态布局；DSH 插件里有对应的空间工具，图片可以按本地路径直接传。

### 从旧版本升级

- Android 从 0.0.2 或更早升上来的，仍然需要手动装一次：那几个版本的应用内更新带着路径检查缺陷，会在安装环节被拦下。装上 0.1.1 之后就已经恢复正常，这一版可以直接应用内更新。
- Android 展示版本 `0.1.2`，基础构建号 `7`，签名密钥与 applicationId 不变。不要为了安装而卸载并丢失数据。
- Windows 沿用完整载荷替换与失败恢复；不要在应用运行时直接覆盖安装目录。
- 服务端需要同步升级才能提供空间接口。旧服务端不会让聊天失败，只在空间入口提示能力不可用。

### 已知边界

- 空间这一版仍未在真机验收：Android 相册选图、Windows 文件对话框、折叠屏真机、真实模型识图与工具组合都没有跑过。
- 第一版不含：推荐算法、关注/好友流、可见范围设置、视频说说、评论图片、已发布内容编辑、空间装修、agent 自动刷流。

### 打包

Windows ZIP 继续自带最小 FFmpeg 8.1.3 与 zlib 1.3.1。从这一版起，测试包和正式发布都使用同一份固定校验的依赖产物，不再每次从源码重编 —— 依赖的归档哈希、目录树 digest 和构建脚本一致性都在发布前校验。下载后可用随 Release 提供的 `SHA256SUMS` 检查完整性；校验和不等于独立数字签名。
