## BB 0.1.3

本版只动空间的大图查看器，桌面端加了翻页手段。空间其它功能与 0.1.2 相同。

### 桌面端大图查看器

- **左右箭头**：鼠标点两侧的箭头翻页，第一张没有「上一张」、最后一张没有「下一张」。之前只有滑动，桌面用户看不出还能翻。
- **方向键修好了**：←/→ 之前按下没反应，因为键被系统的焦点跳转截走了。改成显式声明的快捷键之后不再受影响。Esc 关闭同样走这条路径。

移动端保持原样，仍然是滑动翻页，不显示箭头 —— 手机上没有悬停可以藏，箭头会盖在照片上。

### 空间

说说流、草稿、任意深度回复、转发链、删除语义、已读与浏览分离、通知路由，手机 / PC / 折叠屏三形态布局；DSH 插件里有对应的空间工具，图片可以按本地路径直接传。

### 从旧版本升级

- Android 展示版本 `0.1.3`，基础构建号 `8`，签名密钥与 applicationId 不变。0.1.1 及以后可以直接应用内更新。
- Windows 沿用完整载荷替换与失败恢复；不要在应用运行时直接覆盖安装目录。
- 服务端需要同步升级才能提供空间接口。旧服务端不会让聊天失败，只在空间入口提示能力不可用。

### 已知边界

- 方向键这条只做了 widget 测试：测试环境没法完全复现「焦点被列表控件抢走」的现场，需要装上实际按一次确认。箭头按钮可以直接看见，装上即可验证。
- 空间仍未在真机验收：Android 相册选图、Windows 文件对话框、折叠屏真机、真实模型识图与工具组合都没有跑过。
- 第一版不含：推荐算法、关注/好友流、可见范围设置、视频说说、评论图片、已发布内容编辑、空间装修、agent 自动刷流。

### 打包

Windows ZIP 自带最小 FFmpeg 8.1.3 与 zlib 1.3.1。测试包与正式发布使用同一份固定校验的依赖产物，发布前校验归档哈希、目录树 digest 与构建脚本一致性。下载后可用随 Release 提供的 `SHA256SUMS` 检查完整性；校验和不等于独立数字签名。
