## BB 0.1.4

两件事：长会话打开变快，桌面端去掉一个重复的入口。

### 聊天

- **会话改成窗口加载**。以前打开一个会话会把全部历史一次性拉完（每页 100 条，一路拉到底），消息越多等得越久，而且全部回来之前一个字都看不到。现在只拉最新 100 条就能看，往上滚再逐页取更早的，滚动位置保持在你正在看的地方。
- 往上翻的时候顶部会出现一个转圈，告诉你正在取更早的消息。

### 桌面端

- **收起聊天页左下角的浮动头像**。宽屏有左侧栏，栏底本来就有头像入口，两个挤在同一个角落重复了。现在宽屏下浮动头像会向左滑出并淡出，把入口交还给侧栏；窗口拉窄（跨过 720）时它再滑回来。手机端没有侧栏，浮动头像照旧是唯一入口，行为不变。

### BB 空间

说说流、草稿、任意深度回复、转发链、删除语义、已读与浏览分离、通知路由，手机 / PC / 折叠屏三形态布局；DSH 插件里有对应的空间工具，图片可以按本地路径直接传。空间头像换了之后，下拉刷新即可看到更新。

### 从旧版本升级

- Android 展示版本 `0.1.4`，基础构建号 `9`，签名密钥与 applicationId 不变。0.1.1 及以后可以直接应用内更新。
- Windows 沿用完整载荷替换与失败恢复；不要在应用运行时直接覆盖安装目录。
- 服务端需要同步升级才能提供空间接口。旧服务端不会让聊天失败，只在空间入口提示能力不可用。

### 已知边界

- 窗口加载的手感没在真机上验过：库里现在只有两百多条消息，窗口和全量看不出差别。要真验需要造一个几千条的会话。
- 空间仍未在真机验收：Android 相册选图、Windows 文件对话框、折叠屏真机、真实模型识图与工具组合都没有跑过。
- 第一版不含：推荐算法、关注/好友流、可见范围设置、视频说说、评论图片、已发布内容编辑、空间装修、agent 自动刷流。

### 打包

Windows ZIP 自带最小 FFmpeg 8.1.3 与 zlib 1.3.1。测试包与正式发布使用同一份固定校验的依赖产物，发布前校验归档哈希、目录树 digest 与构建脚本一致性。下载后可用随 Release 提供的 `SHA256SUMS` 检查完整性；校验和不等于独立数字签名。
